# Terrible Enfant — Macro Strategy & Roadmap

Interactive planning tool for the Freequency x Terrible Enfant Brazil launch (EN / PT / ES).

- **index.html** — English (canonical)
- **pt.html** — Portuguese
- **es.html** — Spanish

Values typed into the tool are saved in your browser automatically. Use **Copy share link** to generate a URL with all the numbers embedded and send it to someone — they will open the exact same scenario.
